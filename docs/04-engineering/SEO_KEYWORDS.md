# SEO 目標關鍵字調研（台灣・繁中）

> 調研日期：2026-07-03。方法：Google autocomplete（zh-TW/gl=tw）挖真實搜尋變體 ＋ 三組並行 SERP 競爭分析（修行方法／教義概念／經典人物，共 18 詞）。
> 背景：上線 11 天 GSC 數據證實「romanized 巴利單字＋經號」無搜尋需求；本文件將 SEO 目標改為「日常會搜尋的中文詞」。
> 狀態：調研完成，**尚未動工**。動工時逐項勾銷。

## 核心發現（全部 18 詞共通）

1. **無一競品提供「巴利原典出處＋逐句白話＋阿含對照」**。現有 SERP 清一色是「大師開示體」（法鼓山/佛光山/中台）與「百科列點體」（維基/百度），引經只給經名不給可點原文。這是 sutta.io 的結構性護城河。
2. **莊春江 agama.buddhason.org 能穩排第一頁** → Google 願意給原典型內容排名，此路可走。
3. 多個詞的前排是論壇（phpBB）、20 年前的靜態頁、個人部落格、簡體轉載 → 繁中優質內容真空帶。
4. 版型建議（每個概念頁固定結構，兼打 featured snippet 與 AEO/AI 引用）：
   **一句話定義 → 原典出處與白話 → 逐項定義（引經文段落，深連結研經頁）→ 與大乘詮釋的關係 → 站內相關經文/詞條連結**。概念頁彼此互鏈成主題叢集（四聖諦↔八正道↔十二因緣↔四念處）。

## 與 L1/L2 鐵則的相容方式

概念頁＝新內容型態：解說文字屬 L2（AI 生成、掛 AI 標示、人工校稿後上線），引文全部來自站內 L1 段落（深連結研經頁錨點）；涉及站外經典（SN/DN）僅具名引用出處不轉載全文。不裁決宗派教義；「與大乘詮釋的關係」段落採並陳不裁決。

## 建議執行順序

1. **零成本先行**：既有頁 title/description 改中文概念導向（MN10「念處經・四念處」、MN118「安般念・觀呼吸」、MN141「諦分別經・四聖諦八正道」、MN9「正見經」、字典頁維持現行長尾策略）。
2. **第一梯隊 5 頁**（#1–#5）：兩頁是索引/導覽型（複用既有內容，接近零生成成本），三頁是概念頁（需 L2 生成＋人工校稿）。
3. 觀察 2–4 週 GSC 曝光，有訊號再擴第二梯隊；概念頁互鏈成叢集。
4. 每日 SEO 大腦層的優化對象改為本清單（striking-distance 監控這些詞），不再微調巴利單字頁。
