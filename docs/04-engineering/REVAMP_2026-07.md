# sutta.io 全站改版計劃（2026-07）

> 目標：把主題頁已驗證的優化原則——**每頁單一明確目標、少字、answer-first、內容依屬性切分頁、版面對齊 design-token、親眼截圖驗證**——系統性套用到**全站每一種頁型**。**中文為主，`/en` 最後做**。
>
> 進度追蹤：完成一項就把 `[ ]` 改成 `[x]`，並在該行末註記完成日期。此檔是跨 session 的單一進度來源。

## 固定驗證流程（每一項都必走，不可只 grep）
1. `pnpm -C site build`（`prebuild` 會自動跑 `scripts/check-tokens.mjs` 擋未定義 token）。
2. `node scripts/shot.mjs <改到的頁…>`（cwd=site）→ 截桌機＋手機圖到 `site/.shots/`。
3. **用 Read 工具開圖親眼看**排版（間距/對齊/重疊/一頁高/深色）。沒看過畫面＝沒驗證。
4. commit → push → 部署後用「只有新版才有」的訊號驗證上線。
細節見記憶 `sutta-io-visual-verify-process`。
